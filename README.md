# Responsive Resume / Portfolio Website

This is a frontend-only capstone starter project built with HTML, CSS, and vanilla JavaScript.

## Features

- Semantic HTML sections
- Sticky navigation with smooth scrolling
- Responsive layout for desktop and mobile
- Contact form with email validation
- Contact submissions saved in browser localStorage
- Admin login and response viewer
- Light and dark mode with saved preference

## Admin Login

- Username: `admin`
- Password: `1234`

## How to Run

Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## What to Customize

- Replace `Your Name` with your real name.
- Replace the sample email, location, education, skills, and projects.
- Add screenshots or links for your real projects if required by your teacher.
